#SmartCredit_UTVT

##Descripciones

Esta aplicacion lo que busca es poder hecer pagaso mensuales aprestamos solicitados, mostrando y presentando esquemas acerca de los intereses e IVA, por otro lado tomando en cuenta sus divisas en monedas extrajeras como es en este caso el dolar y el euro que estan usando una API externa para poder tener los tipos de cambio.

##Tecnologias a usar

Las tecnologias implementadas y usada spara el sesarrollo de esta aplicacion fueron en gran parte html, bootstrap, js por otro lado para las divisas haciendo uso de los fecht API, ademas de node.js para hacer puebas unitarias,
